# amscheck-polyglot

Planted on purpose for AMS's end-to-end test of its static scanners: likely bugs for Ruff,
Biome and revive, an injection and an `eval` for Opengrep, old dependencies for OSV-Scanner,
Trivy and the deprecation and end-of-life checks, and a made-up API key for Betterleaks.
Nothing here is built or run by the application, and the key is not a real credential.
